# iPhone Launcher voor Samsung S24

Een iPhone-geïnspireerde Android launcher voor de Galaxy S24.

## Inbegrepen
- iPhone-achtige app-grid met afgeronde app-iconen
- App zoeken
- Onderste dock
- Bedieningspaneel-achtige overlay
- Apps direct openen
- Geschikt als standaard Home/launcher-app
- GitHub Actions bouwt automatisch een debug APK

Dit project gebruikt geen Apple-logo's of Apple-systeembestanden; de interface is iOS-geïnspireerd.
